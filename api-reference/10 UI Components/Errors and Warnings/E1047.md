##### shortDescription
Occurs in the FilterBuilder UI component if the [filter expression](/api-reference/10%20UI%20Components/dxFilterBuilder/1%20Configuration/value.md '/Documentation/ApiReference/UI_Components/dxFilterBuilder/Configuration/#value') contains a data field that is not defined in the [fields](/api-reference/10%20UI%20Components/dxFilterBuilder/1%20Configuration/fields '/Documentation/ApiReference/UI_Components/dxFilterBuilder/Configuration/#fields') array.

---
Occurs in the DataGrid and TreeList if the [filter expression](/Documentation/ApiReference/UI_Components/dxDataGrid/Configuration/#filterValue) references a column that does not exist or a column where filtering is disabled ([allowFiltering](/Documentation/ApiReference/UI_Components/dxDataGrid/Configuration/columns/#allowFiltering) or [allowHeaderFiltering](/Documentation/ApiReference/UI_Components/dxDataGrid/Configuration/columns/#allowHeaderFiltering) is set to false).

Check to ensure that the data field used in the filter expression exists in the **fields** array.
