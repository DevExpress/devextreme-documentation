##### shortDescription
Occurs when the **osm** map provider cannot find a compatible OpenLayers API.

---
Install and register OpenLayers for a modular application, or load its browser build before you initialize the Map. Do not mix an incomplete custom OpenLayers object with the browser integration.

See [OpenStreetMap Provider](/concepts/05%20UI%20Components/Map/12%20OpenStreetMap%20Provider/00%20Overview.md '/Documentation/Guide/UI_Components/Map/OpenStreetMap_Provider/') for setup instructions and [Troubleshooting](/concepts/05%20UI%20Components/Map/12%20OpenStreetMap%20Provider/35%20Troubleshooting.md '/Documentation/Guide/UI_Components/Map/OpenStreetMap_Provider/Troubleshooting/') for package resolution issues.
