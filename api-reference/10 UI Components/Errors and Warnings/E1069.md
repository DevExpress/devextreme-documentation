##### shortDescription
Occurs in the Map with [provider](/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider) set to *"osm"* when a compatible version of OpenLayers is not loaded.

---
To resolve this error, load OpenLayers before Map initialization:

- In modular applications, install the `ol` package and import the `devextreme/ui/map/openlayers` module.
- In applications that use script references, load the OpenLayers browser build that defines the global `ol` object.

This error also occurs if the loaded OpenLayers build is incomplete or outdated.
