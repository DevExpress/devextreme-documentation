##### shortDescription
An error occurred while communicating with the map service. See the map service documentation.

---
If the [provider](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/provider.md '/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider') is *"osm"*, the Map also logs this warning if:

- The **providerConfig**.[calculateLocation](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/providerConfig/calculateLocation.md '/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#calculateLocation') promise is rejected or resolves with **undefined** or invalid coordinates
- The **providerConfig**.[calculateRoute](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/providerConfig/calculateRoute.md '/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#calculateRoute') promise is rejected or resolves with an invalid [OsmRouteResult](/api-reference/10%20UI%20Components/dxMap/9%20Types/OsmRouteResult '/Documentation/ApiReference/UI_Components/dxMap/Types/OsmRouteResult/') value

The Map does not display unresolved [routes](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/routes '/Documentation/ApiReference/UI_Components/dxMap/Configuration/routes/') and sets unresolved locations to `{lat: 0, lng: 0}` for the following properties:

- [center](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/center '/Documentation/ApiReference/UI_Components/dxMap/Configuration/center/')
- **markers[]**.[location](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/markers/location '/Documentation/ApiReference/UI_Components/dxMap/Configuration/markers/location/')

Ensure that your **calculateLocation** and **calculateRoute** definitions return valid values.
