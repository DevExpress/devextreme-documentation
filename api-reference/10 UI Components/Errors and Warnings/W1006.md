##### shortDescription
An error occurred while communicating with the map service. See the map service documentation.

---
If [provider](/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider) is *"osm"*, the Map also logs this warning in the following instances:

- The **providerConfig**.[calculateLocation](/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#calculateLocation) promise is rejected or resolves with **undefined** or invalid coordinates
- The **providerConfig**.[calculateRoute](/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#calculateRoute) promise is rejected or resolves with an invalid [OsmRouteResult](/Documentation/ApiReference/UI_Components/dxMap/Types/OsmRouteResult/) value

The Map does not display unresolved [routes](/Documentation/ApiReference/UI_Components/dxMap/Configuration/routes/) and sets unresolved locations to `{lat: 0, lng: 0}` for the following properties:

- [center](/Documentation/ApiReference/UI_Components/dxMap/Configuration/center/)
- **markers[]**.[location](/Documentation/ApiReference/UI_Components/dxMap/Configuration/markers/location/)

Ensure that your **calculateLocation** and **calculateRoute** definitions return valid values.
