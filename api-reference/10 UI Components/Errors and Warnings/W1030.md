##### shortDescription
Occurs in the Map with [provider](/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider) set to *"osm"* when **providerConfig**.[tileServer](/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#tileServer) does not specify a tile URL for the current map type.

---
If the warning occurs at initialization, the Map does not display tiles. If the warning occurs when the map type changes, the Map keeps the current tiles. Assign a URL template or an [OsmTileServerConfig](/Documentation/ApiReference/UI_Components/dxMap/Types/OsmTileServerConfig/) object with a [url](/Documentation/ApiReference/UI_Components/dxMap/Types/OsmTileServerConfig/#url) to **tileServer**. If **tileServer** is a function, ensure that it synchronously returns a tile source for each map type.
