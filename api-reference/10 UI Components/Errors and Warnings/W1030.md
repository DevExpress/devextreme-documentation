##### shortDescription
Occurs when **providerConfig.tileServer** does not provide a tile source for the **osm** map provider.

---
Specify a tile URL or an **OsmTileServerConfig** object with a nonempty **url**. A tile source selection function must return a configuration for the requested map type.

The Map does not use a public tile server automatically. Other features, such as markers, can work without a tile background. See [Configure a Tile Service](/concepts/05%20UI%20Components/Map/12%20OpenStreetMap%20Provider/05%20Configure%20a%20Tile%20Service.md '/Documentation/Guide/UI_Components/Map/OpenStreetMap_Provider/Configure_a_Tile_Service/').
