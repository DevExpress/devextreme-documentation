##### shortDescription
Occurs in the Map with [provider](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/provider.md '/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider') set to *"osm"* when a location is specified as an address string but **providerConfig**.[calculateLocation](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/providerConfig/calculateLocation.md '/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#calculateLocation') is not specified.

---
The Map replaces each unresolved address with coordinates {lat: 0, lng: 0} (for **center** and **markers**) and does not display **routes** that contain unresolved addresses. Implement **calculateLocation** to convert addresses to coordinates or specify locations as numeric coordinates.
