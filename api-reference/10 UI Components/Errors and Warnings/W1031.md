##### shortDescription
Occurs in the Map with [provider](/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider) set to *"osm"* when a location is specified as an address string but **providerConfig**.[calculateLocation](/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#calculateLocation) is not specified.

---
The Map replaces each unresolved address with coordinates {lat: 0, lng: 0} (for **center** and **markers**) and does not display **routes** that contain unresolved addresses. Implement **calculateLocation** to convert addresses to coordinates or specify locations as numeric coordinates.
