##### shortDescription
Occurs in the Map with the *"osm"* [provider](/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider) when a location is an address string but **providerConfig**.[calculateLocation](/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#calculateLocation) is not specified.

---
The Map replaces each unresolved address with latitude 0 and longitude 0 (for **center** and **markers**) and does not display **routes** that contain unresolved addresses. Implement **calculateLocation** to convert addresses to coordinates, or specify locations as numeric coordinates.
