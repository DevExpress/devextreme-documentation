##### shortDescription
Occurs when the **osm** map provider needs to resolve a location string but **calculateLocation** is not configured.

---
Implement [providerConfig.calculateLocation](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/providerConfig/calculateLocation.md '/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#calculateLocation'), or specify numeric coordinates instead of addresses and place names.

An unresolved center or marker location falls back to **{ lat: 0, lng: 0 }**. A route with an unresolved waypoint is skipped. See [Calculate Locations](/concepts/05%20UI%20Components/Map/12%20OpenStreetMap%20Provider/10%20Calculate%20Locations.md '/Documentation/Guide/UI_Components/Map/OpenStreetMap_Provider/Calculate_Locations/').
