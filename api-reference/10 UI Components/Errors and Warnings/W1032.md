##### shortDescription
Occurs in the Map with [provider](/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider) set to *"osm"* when a tile source does not specify [attribution](/Documentation/ApiReference/UI_Components/dxMap/Types/OsmTileServerConfig/#attribution).

---
The Map displays tiles without attribution. Use an [OsmTileServerConfig](/Documentation/ApiReference/UI_Components/dxMap/Types/OsmTileServerConfig/) object instead of a URL template and specify the required copyright notices and links for your tile and data providers in its **attribution** field.
