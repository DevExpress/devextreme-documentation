##### shortDescription
Occurs when a tile source for the **osm** map provider does not specify attribution.

---
Set [OsmTileServerConfig.attribution](/api-reference/10%20UI%20Components/dxMap/9%20Types/OsmTileServerConfig/attribution.md '/Documentation/ApiReference/UI_Components/dxMap/Types/OsmTileServerConfig/#attribution') to the notice required by your tile and data providers. The Map does not supply it automatically.

See [Configure a Tile Service](/concepts/05%20UI%20Components/Map/12%20OpenStreetMap%20Provider/05%20Configure%20a%20Tile%20Service.md '/Documentation/Guide/UI_Components/Map/OpenStreetMap_Provider/Configure_a_Tile_Service/').
