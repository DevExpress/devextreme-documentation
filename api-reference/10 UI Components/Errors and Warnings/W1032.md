##### shortDescription
Occurs in the Map with the *"osm"* [provider](/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider) when a tile source does not specify [attribution](/Documentation/ApiReference/UI_Components/dxMap/Types/OsmTileServerConfig/#attribution).

---
The Map displays tiles without attribution. Use an [OsmTileServerConfig](/Documentation/ApiReference/UI_Components/dxMap/Types/OsmTileServerConfig/) object (not a URL template) and specify the copyright notices and links that your tile and data providers require in its **attribution** field.
