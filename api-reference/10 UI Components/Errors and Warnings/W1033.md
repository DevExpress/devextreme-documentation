##### shortDescription
Occurs in the Map with [provider](/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider) set to *"osm"* when a [route](/Documentation/ApiReference/UI_Components/dxMap/Configuration/routes/) contains two or more locations but **providerConfig**.[calculateRoute](/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#calculateRoute) is not specified.

---
The Map does not display these routes or connect their locations with straight lines. Implement **calculateRoute** to return route geometry from an external routing service or predefined coordinates.
