##### shortDescription
Occurs when the **osm** map provider needs to calculate a route but **calculateRoute** is not configured.

---
Implement [providerConfig.calculateRoute](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/providerConfig/calculateRoute.md '/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#calculateRoute') to return route geometry. The Map does not include a routing service and skips routes that it cannot calculate.

See [Calculate Routes](/concepts/05%20UI%20Components/Map/12%20OpenStreetMap%20Provider/15%20Calculate%20Routes.md '/Documentation/Guide/UI_Components/Map/OpenStreetMap_Provider/Calculate_Routes/').
