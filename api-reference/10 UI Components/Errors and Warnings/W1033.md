##### shortDescription
Occurs in the Map with the *"osm"* [provider](/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider) when a [route](/Documentation/ApiReference/UI_Components/dxMap/Configuration/routes/) contains two or more locations but **providerConfig**.[calculateRoute](/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#calculateRoute) is not specified.

---
The Map does not display these routes and does not connect their locations with straight lines. Implement **calculateRoute** to obtain route geometry from a routing service.
