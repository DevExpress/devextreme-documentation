##### shortDescription
Occurs in the Map with [provider](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/provider.md '/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider') set to *"osm"* when a [route](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/routes '/Documentation/ApiReference/UI_Components/dxMap/Configuration/routes/') contains two or more locations but **providerConfig**.[calculateRoute](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/providerConfig/calculateRoute.md '/Documentation/ApiReference/UI_Components/dxMap/Configuration/providerConfig/#calculateRoute') is not specified.

---
The Map does not display these routes or connect their locations with straight lines. Implement **calculateRoute** to return route geometry from an external routing service or predefined coordinates.
