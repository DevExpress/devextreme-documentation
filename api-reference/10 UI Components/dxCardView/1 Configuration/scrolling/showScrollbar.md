##### shortDescription
Specifies when the UI component displays scrollbars.

---

[note]

**showScrollbar** values behave as follows when the UI component uses native scrolling (see [useNative](/api-reference/10%20UI%20Components/dxCardView/1%20Configuration/scrolling/useNative.md '{currentpath}/#useNative')):

- *"always"*, *"onScroll"*, and *"onHover"*: scrollbar visibility depends on the platform.
- *"never"*: the component hides scrollbars and disables user scrolling.

[/note]
