##### shortDescription
Specifies whether the tool call succeeded or failed.

---
Set this field to `'error'` to mark a failed call. The Chat component adds an "Error" tag to the header of the tool call block and highlights the [result](/api-reference/10%20UI%20Components/dxChat/9%20Types/ToolCall/result.md '/Documentation/ApiReference/UI_Components/dxChat/Types/ToolCall/#result') in the block.
