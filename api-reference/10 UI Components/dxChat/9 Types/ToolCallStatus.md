##### shortDescription
Specifies the status of a tool call.

---
Use this type to define the outcome of a tool call in the [status](/api-reference/10%20UI%20Components/dxChat/9%20Types/ToolCall/status.md '/Documentation/ApiReference/UI_Components/dxChat/Types/ToolCall/#status') field.

This type accepts the following values:

- `'success'` - The tool call succeeded.
- `'error'` - The tool call failed.
