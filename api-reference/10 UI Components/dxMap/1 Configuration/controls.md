---
##### shortDescription
Specifies whether or not map UI component controls are available.

---
Assign a Boolean value to this property to enable or disable all controls at once - both the map navigation control and the map type control.

If [provider](/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider) is *"osm"*, this property does not affect the attribution control (**OsmTileServerConfig**.[attribution](/Documentation/ApiReference/UI_Components/dxMap/Types/OsmTileServerConfig/#attribution)).
