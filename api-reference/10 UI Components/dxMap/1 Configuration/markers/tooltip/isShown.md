---
id: dxMap.Options.markers.tooltip.isShown
type: Boolean
default: false
---
---
##### shortDescription
Specifies whether a tooltip is visible by default or not.

---

If [provider](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/provider.md '/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider') is *"osm"* and you set **isShown** to **true**, the tooltip appears when the Map creates the marker, before **markers[]**.[onClick](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/markers/onClick.md '/Documentation/ApiReference/UI_Components/dxMap/Configuration/markers/#onClick') can customize the tooltip.
