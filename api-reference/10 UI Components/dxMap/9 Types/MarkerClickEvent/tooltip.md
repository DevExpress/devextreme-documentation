##### shortDescription
The marker's Popover instance.

---
Available only for **osm** markers with a tooltip. Use the instance's public [options](/Documentation/ApiReference/UI_Components/dxPopover/Configuration/) and [methods](/Documentation/ApiReference/UI_Components/dxPopover/Methods/) to customize it.

See [Customize Marker Tooltips](/Documentation/Guide/UI_Components/Map/OpenStreetMap_Provider/Customize_Marker_Tooltips/) for examples and the timing of the first display.
