##### shortDescription
The clicked marker's Popover instance.

---
**MarkerClickEvent**.**tooltip** is only available for the *"osm"* [provider](/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider). This field contains the [Popover](/Documentation/ApiReference/UI_Components/dxPopover/) instance that displays the marker's [tooltip](/Documentation/ApiReference/UI_Components/dxMap/Configuration/markers/tooltip/) (or **undefined** if the marker has no tooltip).

Use Popover [properties](/Documentation/ApiReference/UI_Components/dxPopover/Configuration/) and [methods](/Documentation/ApiReference/UI_Components/dxPopover/Methods/) to customize the tooltip (for instance, to display a title or a Close button).
