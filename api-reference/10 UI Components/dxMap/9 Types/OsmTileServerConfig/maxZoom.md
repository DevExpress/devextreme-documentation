id: OsmTileServerConfig.maxZoom
type: Number
---
---
##### shortDescription
The highest zoom level that the tile source supports. Default: 19.

---
The Map does not request tiles for zoom levels above this value. Users can still zoom in further. At these levels, the Map enlarges tiles from the **maxZoom** level.
