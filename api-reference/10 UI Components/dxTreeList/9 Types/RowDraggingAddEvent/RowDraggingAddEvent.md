---
Use this type to annotate the argument of an [onAdd](/Documentation/ApiReference/UI_Components/dxTreeList/Configuration/rowDragging/#onAdd) handler. Refer to the handler's description for details about the event argument. The **TRowData** and **TKey** type parameters specify the row data and key types.
