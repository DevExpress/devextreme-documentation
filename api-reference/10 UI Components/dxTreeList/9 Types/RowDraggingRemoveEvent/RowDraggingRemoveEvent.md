##### shortDescription
The type of the **rowDragging**.[onRemove](/Documentation/ApiReference/UI_Components/dxTreeList/Configuration/rowDragging/#onRemove) event handler's argument.

---
Use this type to annotate the argument of an [onRemove](/Documentation/ApiReference/UI_Components/dxTreeList/Configuration/rowDragging/#onRemove) handler. Refer to the handler's description for details about the event argument. The **TRowData** and **TKey** type parameters specify the row data and key types.
