##### shortDescription
Describes the drop location and asynchronous completion of a row reorder operation.

---
This type supplies the **dropInsideItem** and **promise** fields for DataGrid and TreeList **RowDraggingReorderEvent** arguments. Use these fields to update the TreeList hierarchy or wait for an asynchronous data source update.
