##### shortDescription
Custom data associated with the source UI component.

---
Set the source component's [data](/api-reference/10%20UI%20Components/GridBase/1%20Configuration/rowDragging/data.md '/Documentation/ApiReference/UI_Components/dxDataGrid/Configuration/rowDragging/#data') property to pass application-specific information to row-dragging handlers. Use **fromData** to identify or access this information during a transfer between components.
