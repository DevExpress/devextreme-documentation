---
##### shortDescription
The row's target position.

---
Use this field to determine where to insert the dragged row. The value is **-1** if the row is dragged away from the UI component. When paging is enabled, the index is relative to the active page. When virtual scrolling is enabled, the index is relative to the top visible row.
