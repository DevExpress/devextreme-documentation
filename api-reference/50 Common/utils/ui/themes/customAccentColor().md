##### shortDescription
Gets the custom accent color (primary color) applied to the active Fluent Next stylesheet.

##### return: String
The custom accent color or an empty string if no custom accent color is defined.

---
**customAccentColor()** returns the `--dx-accent-color` value defined in the `:root` scope. The returned value retains the format you specify (for instance, *"SlateBlue"* or *"#6A5ACD"*).
