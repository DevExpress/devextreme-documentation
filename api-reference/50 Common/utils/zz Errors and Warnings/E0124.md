##### shortDescription
Occurs when the 30-day DevExtreme trial period has expired.

---
Once the trial period expires, you can no longer use DevExtreme. Note that you cannot redistribute DevExtreme during or after the trial period. The console message lists the following information:

- The DevExtreme version and the DevExpress product libraries that require a license.
- The subscriptions that include these libraries.
- The ID and source of the license key used in your application.

Follow the steps below to resolve this error:

1. Purchase a license on the [DevExtreme Purchase](https://js.devexpress.com/Buy/) page. If you already own a license, skip this step.
2. Obtain your DevExpress license key from the [DevExpress Download Manager](https://www.devexpress.com/ClientCenter/DownloadManager/) and register the key on your machine.
3. Run the `devextreme-license` CLI tool to regenerate the DevExtreme runtime key.
4. Specify the generated key in [GlobalConfig](/Documentation/ApiReference/Common/Object_Structures/GlobalConfig/).

If you own a valid license and this error persists, submit a support ticket in the [DevExpress Support Center](https://supportcenter.devexpress.com/ticket/create). For assistance with your purchase, contact the <a href="mailto:clientservices@devexpress.com">DevExpress Client Services Team</a>.

For additional information, refer to the following help topic: [Licensing](/Documentation/Guide/Common/Licensing/).
