##### shortDescription
Occurs when you pass an invalid value to the [customAccentColor(color)](/Documentation/ApiReference/Common/utils/ui/themes/#customAccentColorcolor) method.

---
**customAccentColor(color)** ignores values that are not valid CSS colors and does not change the previous accent color. The following values cause this warning:

- Values that the browser does not recognize as CSS colors (for instance, misspelled color names or color functions with missing arguments)
- *"currentColor"* and CSS keywords (*"inherit"*, *"initial"*, *"unset"*, *"revert"*, and *"revert-layer"*) that do not specify a color

To resolve this warning, pass a valid CSS color value (for instance, *"SlateBlue"*, *"#6A5ACD"*, or *"var(--my-brand-color)"*). To remove a custom accent color, pass `null` or an empty string.
