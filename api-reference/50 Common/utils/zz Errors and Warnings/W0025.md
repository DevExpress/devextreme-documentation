##### shortDescription
Occurs when you pass a color to the [customAccentColor(color)](/Documentation/ApiReference/Common/utils/ui/themes/#customAccentColorcolor) method while the active theme is not a Fluent Next theme.

---
Only Fluent Next themes support custom accent colors. Other themes ignore the color that **customAccentColor(color)** specifies, including legacy Fluent themes.

To use a custom accent color, apply a Fluent Next theme. To change the accent color of a Generic, Material, or Fluent theme, create a custom theme in [ThemeBuilder](/Documentation/Guide/Themes_and_Styles/ThemeBuilder/).
