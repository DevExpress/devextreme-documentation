##### shortDescription
Occurs when you pass a color to the [customAccentColor(color)](/Documentation/ApiReference/Common/utils/ui/themes/#customAccentColorcolor) method while the active theme is not a Fluent Next theme.

---
Only Fluent Next themes support custom accent colors. Other themes (including Fluent themes) ignore the color that **customAccentColor(color)** specifies.

Apply a Fluent Next theme to use custom accent colors. To customize Generic, Material, or Fluent themes, refer to the [ThemeBuilder documentation](/Documentation/Guide/Themes_and_Styles/ThemeBuilder/).
