##### shortDescription
Occurs when you pass a color to the [customAccentColor(color)](/api-reference/50%20Common/utils/ui/themes/customAccentColor(color).md '/Documentation/ApiReference/Common/utils/ui/themes/#customAccentColorcolor') method when a Fluent Next theme is not active.

---
Only Fluent Next themes support custom accent colors. Other themes, including Fluent themes, ignore the color specified by **customAccentColor(color)**.

Apply a Fluent Next theme to use custom accent colors. To customize Generic, Material, or Fluent themes, refer to the [ThemeBuilder documentation](/concepts/60%20Themes%20and%20Styles/08%20ThemeBuilder '/Documentation/Guide/Themes_and_Styles/ThemeBuilder/').
