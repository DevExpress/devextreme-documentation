Load the OpenLayers script (`ol.js`) and stylesheet (`ol.css`) before Map initialization:

    <!-- tab: index.html -->
    <head>
        <!-- ... -->
        <link rel="stylesheet" href="/lib/ol/ol.css">
        <script src="/lib/ol/ol.js"></script>
    </head>

Refer to the OpenLayers website for download options: [OpenLayers - Download](https://openlayers.org/download/).
