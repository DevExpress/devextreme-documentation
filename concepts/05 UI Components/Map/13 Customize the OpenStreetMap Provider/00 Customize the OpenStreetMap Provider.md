If [provider](/api-reference/10%20UI%20Components/dxMap/1%20Configuration/provider.md '/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider') is *"osm"*, the Map uses [OpenLayers](https://openlayers.org/) to display maps. This provider displays marker tooltips in DevExtreme [Popover](/api-reference/10%20UI%20Components/dxPopover '/Documentation/ApiReference/UI_Components/dxPopover/') instances. Use OpenLayers and dxPopover APIs to customize the map and its marker tooltips.
