The **markers[]**.[onClick](/Documentation/ApiReference/UI_Components/dxMap/Configuration/markers/#onClick) handler receives the clicked marker's Popover instance in **e.tooltip**. The Map calls this handler before it displays or hides the tooltip. When a user clicks a marker with a hidden tooltip, the tooltip appears with the settings that you specify in the handler. To keep the tooltip hidden, assign a Popover [onShowing](/Documentation/ApiReference/UI_Components/dxPopover/Configuration/#onShowing) handler that sets **e.cancel** to `true`.
