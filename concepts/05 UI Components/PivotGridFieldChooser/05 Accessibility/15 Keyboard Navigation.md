You can use the following keys to interact with the DevExtreme PivotGridFieldChooser component:

<table class="dx-table">
    <tr>
        <th>Key</th>
        <th>Action</th>
    </tr>
    <tr>
        <td>Shift + F10</td>
        <td>Opens the context menu.</td>
    </tr>
    <tr>
        <td>Tab / Shift + Tab</td>
        <td>Moves focus to the next or previous fields area.</td>
    </tr>
    <tr>
        <td>Arrow Keys</td>
        <td>Moves focus between fields within an area.<br>Moves focus between items in filter popups and the "All Fields" area.</td>
    </tr>
    <tr>
        <td>Enter / Space</td>
        <td>Sorts fields and toggles their sort order.</td>
    </tr>
    <tr>
        <td>Alt + Down Arrow<br>&#8997; + Down Arrow (Mac)</td>
        <td>Opens the header filter for the focused field.</td>
    </tr>
    <tr>
        <td>Home / End</td>
        <td>Scrolls content to the top/bottom.</td>
    </tr>
</table>
