- **Data Binding**    
TabPanel supports different [data source](/api-reference/30%20Data%20Layer/DataSource '/Documentation/ApiReference/Data_Layer/DataSource/') types and can update displayed items when data is modified.

- **Layout Configuration**    
The component can arrange tabs horizontally or vertically. TabPanel also allows you to [position](/api-reference/10%20UI%20Components/dxTabPanel/1%20Configuration/tabsPosition.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#tabsPosition') tabs along any edge of the component: top, bottom, left, or right.

- **Tab Configuration**    
TabPanel supports tab [icons](/api-reference/_hidden/dxTabPanelItem/icon.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/items/#icon'), [badges](/api-reference/_hidden/dxTabPanelItem/badge.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/items/#badge'), and [titles](/api-reference/_hidden/dxTabPanelItem/title.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/items/#title'). The component allows you to specify the [icon position](/api-reference/10%20UI%20Components/dxTabPanel/1%20Configuration/iconPosition.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#iconPosition') to adjust the layout of tabs that contain icons. You can also configure the [styling mode](/api-reference/10%20UI%20Components/dxTabPanel/1%20Configuration/stylingMode.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#stylingMode') of active tabs, as well as [disable](/api-reference/_hidden/CollectionWidgetItem/disabled.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/items/#disabled') tabs that users should not access.

- **Accessibility and Keyboard Navigation**    
TabPanel [conforms](/concepts/05%20UI%20Components/TabPanel/05%20Accessibility/00%20Accessibility.md '/Documentation/Guide/UI_Components/TabPanel/Accessibility/') to WCAG 2.x, European Accessibility Act (EAA), and Americans with Disabilities Act (ADA) standards. The component supports [keyboard navigation](/concepts/05%20UI%20Components/TabPanel/05%20Accessibility/15%20Keyboard%20Navigation.md '/Documentation/Guide/UI_Components/TabPanel/Accessibility/#Keyboard_Navigation') and custom key handlers. TabPanel also ships with right-to-left ([RTL](/api-reference/10%20UI%20Components/DOMComponent/1%20Configuration/rtlEnabled.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#rtlEnabled')) representation support.

- **Customization**    
You can use templates to define custom markup for [individual TabPanel tabs](/api-reference/_hidden/dxTabPanelItem/tabTemplate.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/items/#tabTemplate') or [all tabs](/api-reference/10%20UI%20Components/dxTabPanel/1%20Configuration/itemTitleTemplate.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#itemTitleTemplate'), and for [individual panels](/api-reference/_hidden/CollectionWidgetItem/template.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/items/#template') or [all panels](/api-reference/10%20UI%20Components/CollectionWidget/1%20Configuration/itemTemplate.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#itemTemplate'). You can also enable or disable [swipe](/api-reference/10%20UI%20Components/dxTabPanel/1%20Configuration/swipeEnabled.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#swipeEnabled') gestures and transition [animations](/api-reference/10%20UI%20Components/dxTabPanel/1%20Configuration/animationEnabled.md '/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#animationEnabled') to customize how users switch between tabs.
