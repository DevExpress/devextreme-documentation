- **Data Binding**    
TabPanel supports different [data source](/Documentation/ApiReference/Data_Layer/DataSource/) types and can update displayed items when data is modified.

- **Layout Configuration**    
The component can arrange tabs horizontally or vertically. TabPanel also allows you to [position](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#tabsPosition) tabs along any edge of the component: top, bottom, left, or right.

- **Tab Configuration**    
TabPanel supports tab [icons](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/items/#icon), [badges](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/items/#badge), and [titles](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/items/#title). The component allows you to specify the [icon position](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#iconPosition) to adjust the layout of tabs that contain icons. You can also configure the [styling mode](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#stylingMode) of active tabs, as well as [disable](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/items/#disabled) tabs that users should not access.

- **Accessibility and Keyboard Navigation**    
TabPanel [conforms](/Documentation/Guide/UI_Components/TabPanel/Accessibility/) to WCAG 2.x, European Accessibility Act (EAA), and Americans with Disabilities Act (ADA) standards. The component supports [keyboard navigation](/Documentation/Guide/UI_Components/TabPanel/Accessibility/#Keyboard_Navigation) and custom key handlers. TabPanel also ships with right-to-left ([RTL](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#rtlEnabled)) representation support.

- **Customization**    
You can use templates to define custom markup for [individual TabPanel tabs](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/items/#tabTemplate) or [all tabs](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#itemTitleTemplate), and for [individual panels](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/items/#template) or [all panels](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#itemTemplate). You can also enable or disable [swipe](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#swipeEnabled) gestures and transition [animations](/Documentation/ApiReference/UI_Components/dxTabPanel/Configuration/#animationEnabled) to customize how users switch between tabs.
