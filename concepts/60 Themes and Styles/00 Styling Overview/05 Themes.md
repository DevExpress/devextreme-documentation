DevExtreme ships with the following built-in themes:

- **Fluent Next**    
[DevExpress Design System](https://docs.devexpress.com/DesignSystem/405636/foundation)-based themes that use CSS variables to declare color, typography, spacing, border, opacity, and shadow styles. Key capabilities include:

    - Predefined accent colors
    - Custom accent colors
    - Light and dark modes
    - Compact mode
    - Theme customization using public `--dxds-*` CSS variables

- **Fluent, Material, and Generic**    
Themes that use SCSS to implement styles. For more information, refer to the following help topic: [Predefined Themes](/Documentation/Guide/Themes_and_Styles/Predefined_Themes/).
