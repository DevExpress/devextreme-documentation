The following naming convention applies to CSS variables in Fluent Next themes:

- `--dxds-*`    
Design System CSS variables that serve as public APIs. Use these variables to customize your DevExtreme-powered application.

- `--dx-*`    
Internal CSS variables used by DevExtreme components. Undocumented variables may change between versions.

- `--dx-viz-*`    
CSS variables used by SVG-based components. For more information, refer to the following help topic: [SVG-Based Component Colors](/Documentation/Guide/Themes_and_Styles/Fluent_Next_Theme_Customization/#CSS_Variables/SVG-Based_Component_Colors).
