Starting with v18.1, DevExtreme hybrid mobile tools have been deprecated, including mobile tools for Visual Studio. Refer to the following blog post for more information: [DevExtreme Hybrid Mobile Tools Deprecation in v18.1](https://community.devexpress.com/blogs/aspnet/archive/2018/02/26/devextreme-hybrid-mobile-tools-deprecation-in-v18-1.aspx).

[Visual Studio tools for DevExtreme ASP.NET MVC 5 Controls](https://docs.devexpress.com/DevExtremeAspNetMvc/400702/get-started/configure-a-project) remain in active development.
