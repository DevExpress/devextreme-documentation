**OsmTileServerConfig**.[attribution](/Documentation/ApiReference/UI_Components/dxMap/Types/OsmTileServerConfig/#attribution) specifies copyright notices and links that the [Map](/Documentation/ApiReference/UI_Components/dxMap/) displays for its tile source when [provider](/Documentation/ApiReference/UI_Components/dxMap/Configuration/#provider) is *"osm"*. The **attribution** field accepts an HTML string. The Map passes this string to OpenLayers, and the library inserts this string into the page as HTML. This behavior makes the Map potentially vulnerable to XSS attacks.

If the **attribution** value comes from an untrusted source, sanitize this value before assignment. Ensure that the sanitized value retains the notices and links required by your tile and data providers.
