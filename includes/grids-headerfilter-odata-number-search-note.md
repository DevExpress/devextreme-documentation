[note] Columns that display numbers require additional configuration to support header filter search if you use an **ODataStore**. Set **columns[]**.**headerFilter**.**search**.[mode]({basewidgetpath}/Configuration/columns/headerFilter/search/#mode) to *"equals"* and specify the data field type in the store's [fieldTypes](/api-reference/30%20Data%20Layer/ODataStore/1%20Configuration/fieldTypes.md '/Documentation/ApiReference/Data_Layer/ODataStore/Configuration/#fieldTypes') property.
