[note]

If you configure a [ButtonGroup](/Documentation/Guide/UI_Components/ButtonGroup/Getting_Started_with_ButtonGroup/) in this template, you can set [widget]({currentpath}/#widget) to *"dxButtonGroup"* to display ButtonGroup items vertically in the overflow menu (if [locateInMenu]({currentpath}/#locateInMenu) is not *"never"*). DevExtreme Toolbar applies the following class to *"dxButtonGroup"* items in the overflow menu to arrange buttons vertically: `dx-toolbar-hidden-button-group`. The text alignment controls in the following demo implement this approach:
