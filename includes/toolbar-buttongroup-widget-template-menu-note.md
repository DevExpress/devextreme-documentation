[note]

If you configure a [ButtonGroup](/Documentation/Guide/UI_Components/ButtonGroup/Getting_Started_with_ButtonGroup/) in this template, you can set [widget]({currentpath}/#widget) to *"dxButtonGroup"* to display ButtonGroup items vertically in the overflow menu when [locateInMenu]({currentpath}/#locateInMenu) is not *"never"*. The text alignment controls in the following demo use this approach:

#include common-demobutton-named with {

    name: "Toolbar - Adaptability"
}
